# sales-analysis-with-power-bi
A Power BI project exploring sales performance, customer trends and data modelling.

## Project Overview
This project was completed as part of my Data Analytics training at TS Academy. It involved analyzing sales data stored in an Excel workbook to identify key business performance indicators, generate meaningful insights, and present the findings through an interactive dashboard. The analysis was carried using Power BI and DAX, and the results were presented through a Power BI dashboard.

## Project Objectives
- Identify and calculate major business KPIs.
- Analyze the data to uncover trends and patterns.
- Generate insights from the identified KPIs.
- Build an interactive dashboard to communicate the findings effectively.
- Incorporate slicers to allow users filter and explore the data dynamically.

## Dataset
The datasets were stored in an Excel workbook, and they were imported into Power BI for preparation and analysis before use for dashboard creation.  
*The dataset can be viewed [here](https://github.com/adaeudoxie/sales-analysis-with-power-bi/blob/main/dataset.xlsx)*

## Tools Used
- **Microsoft Excel**: the datasets were stored in Excel.
- **Power Query**: used to clean, transform, and prepare the data for analysis.
- **DAX**: used to create measures and calculate key performance indicators.
- **Power BI**: used to analyze, model, and visualize the data.

## Analysis & Insights
The KPIs were used to explore sales performance across different dimensions of the dataset. Some key areas include:
- Sales performance across different products, categories, and regions.
- Profitability and its relationship with sales.
- Quantity of gadgets sold.
- Trends in sales performance over time.
- Identification of top- and low-performing regions.

### Business KPIs
- Total Sales: $5.2k
- Total COGS: $2.17m
- Total Profit: $931.91k
- Total Customers: 250

### Key Insight
In the business year analyzed, the business recorded an estimate of **$3.11m** total revenue, and **$932k** total profit. Apple gadgets gathered the most profit with **$197k**, with the brands' headphones and tablets topping the chart with **$44k** in profit.

## The Dashboard
The final analysis was presented through a Power BI dashboard that includes:
- KPI cards for the major business metrics.
- Visualizations highlighting key trends and patterns.
- Interactive slicers for filtering the analysis.
- Charts designed to make comparisons and patterns easier to identify.
*The dashboard can be viewed [here](https://github.com/adaeudoxie/sales-analysis-with-power-bi/blob/main/dashboard.png)*

### Interactive Filters
Slicers were incorporated into the dashboard to allow for interactive filtering and exploration.
